# Mine

## Next Card Up

A training plan built around a rotating three-card deck — Push, Pull, Legs + Arms — so
that missing a day never breaks a schedule. Designed for short sessions, dumbbells and
machines, progressive overload via double progression, and training through a GLP-1
deficit without losing muscle.

Open `next-card-up.html` in a browser, or use the published version on a phone at the gym.
